---
title: Quickstart
description: Declare your types once, write a module, register it, and call it.
---

<Steps>
  <Step title="Declare your types in logic.ts">

`init` returns the definers, typed with your config.

```ts
import {
  init,
  type MutationCtx as Mutation,
  type QueryCtx as Query,
} from "logic-sdk";
import type { DrizzleDb } from "logic-sdk/drizzle/pg";
import type { db } from "./db"; // its type only: modules reach the database through ctx.db
import type { Scope } from "./policies";

type Db = typeof db;

type Config = {
  // Who is calling: your own type, JSON only
  scope: Scope;
  // Queries get a reader (no insert, update or delete), mutations the transaction
  db: DrizzleDb<Db>;
  // What actions and listeners get
  services: { mailer: Mailer; payments: Payments };
  // Settings every function reads as ctx.config: plain data
  config: { app: { url: string } };
};

// For helpers like findBooking(ctx, id)
export type QueryCtx = Query<Config>;
export type MutationCtx = Mutation<Config>;

export const { query, mutation, action, event, listener, createRegistry } = init<Config>();
```

  </Step>
  <Step title="Write your policies in policies.ts">

A policy is a plain, sync function over the scope that says who may call a function. Write them as type guards, and they narrow `ctx.scope`:

```ts
export type Scope = SignedOutScope | MemberScope;

export const anyone = () => true;
export const member = (s: Scope): s is MemberScope => s.actor !== null;
export const staff = (s: Scope): s is StaffScope =>
  s.actor !== null && s.actor.role !== "guest";
```

[Authorization](/docs/concepts/authorization) has the full file and the rules for records.

  </Step>
  <Step title="Write a module">

A module is a folder. Other modules import only its `index.ts`.

```txt
src/bookings/
  index.ts        export * from each public file
  queries.ts
  mutations.ts
  actions.ts
  events.ts
  listeners.ts    reacting to other modules
  data.ts         helpers that take ctx
  schema.ts       tables this module owns
```

```ts
// src/bookings/mutations.ts
/** Cancel a booking and free its dates */
export const cancel = mutation({
  input: z.object({ bookingId: z.uuid() }),
  output: Booking,
  // Who may call it, on every call
  authorize: staff,
  // Adapters (HTTP, oRPC, AI) may publish it
  expose: true,

  async handler(ctx, input) {
    const booking = await findBooking(ctx, input.bookingId);
    if (booking.status === "cancelled") {
      throw ctx.errors.reject("already_cancelled");
    }

    await ctx.run(availability.release, { sourceId: booking.id });
    ctx.emit(cancelled, { bookingId: input.bookingId });

    return setStatus(ctx, booking.id, "cancelled");
  },
});
```

  </Step>
  <Step title="Register your modules in registry.ts">

```ts
import { drizzleAdapter } from "logic-sdk/drizzle/pg";
import * as availability from "./availability";
import * as bookings from "./bookings";

export const registry = createRegistry({
  // Ids come from the keys: "bookings.cancel"
  modules: { bookings, availability },
  database: drizzleAdapter(db),
  services: { mailer, payments },
  // Read env here, at the entry; modules read ctx.config
  config: { app: { url: process.env.APP_URL! } },
});
```

`createRegistry` walks each module's exports and picks up every query, mutation, action, event and listener. A new listener is live as soon as it's exported.

  </Step>
  <Step title="Call it from anywhere">

Bind who is calling once per request, job or test. Every nested call inherits it.

```ts
const caller = registry.as({
  actor,
  accountId,
  locale: "en",
});

await caller.run(bookings.cancel, { bookingId });
```

  </Step>
</Steps>

From here, publish exposed functions over [HTTP](/docs/adapters/fetch) or [oRPC](/docs/adapters/orpc), or read how [authorization](/docs/concepts/authorization) and [transactions](/docs/concepts/transactions) work.
