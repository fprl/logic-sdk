---
title: HTTP (fetch)
description: A web-standard handler that publishes exposed functions as JSON endpoints.
---

```ts
import { toFetchHandler } from "logic-sdk/fetch";

const api = toFetchHandler(registry, {
  basePath: "/api/",
  resolveScope: (request) => scopeFromSession(request),
});
```

It takes a `Request` and returns a `Response`, so it mounts as-is in Workers, Bun, Hono, SvelteKit endpoints and Next.js route handlers:

```ts
// Hono
app.all("/api/*", (c) => api(c.req.raw));
```

## Routes

| Request | Does |
|---|---|
| `POST /api/bookings.confirm` | Runs it with the JSON body as input |
| `GET /api/availability.check?input={...}` | Queries only |

- Only functions with `expose: true` are published. Anything else is a 404, and there's no route that lists them.
- POST needs `content-type: application/json`. That blocks cross-site form posts (CSRF).
- Success is `{ "data": ... }`.

## Errors

Failures are `{ "error": { "kind", "code", "details" } }`, with a status from the error's kind:

| Kind | Status |
|---|---|
| `invalid` | 400 |
| `unauthenticated` | 401 |
| `forbidden` | 403 |
| `not_found` | 404 |
| `conflict` | 409 |
| `rejected` | 422 |
| anything unexpected | 500, without details |

Unexpected errors go to `onError` (default: `console.error`). The map is exported as `statusOf`.

## Signed out

`resolveScope` decides what a request without a session means:

- **This mount also serves public functions:** return a scope with no actor. Functions whose `authorize` needs one answer 403.
- **This mount is entirely session-only:** throw `unauthenticated()` and the client gets a 401.

```ts
import { toFetchHandler, unauthenticated } from "logic-sdk/fetch";

const admin = toFetchHandler(registry, {
  basePath: "/admin/api/",
  resolveScope: async (request) => {
    const session = await auth.getSession(request);
    if (!session) throw unauthenticated();
    return scopeFrom(session);
  },
});
```

## Serverless

Listeners can finish after the response: set `waitUntil` once on the registry. See [Events](/docs/concepts/events#serverless).
