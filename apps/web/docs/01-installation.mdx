---
title: Installation
description: Add the package, a schema library and a database adapter.
---

```bash
npm i logic-sdk zod
```

Any [Standard Schema](https://standardschema.dev) library works for `input` and `output`. These docs use Zod.

## What's in the package

| Import | What it gives you |
|---|---|
| `logic-sdk` | `init`, the definers, `createRegistry`, errors |
| `logic-sdk/drizzle/pg` | `drizzleAdapter(db)`, and jobs in your Postgres: `databaseQueue`, `outbox` |
| `logic-sdk/postgres` | The same two on Postgres with any ORM, and the tables as SQL |
| `logic-sdk/cloudflare` | `cloudflareQueue`, `handleQueue`, `handleScheduled` |
| `logic-sdk/pg-boss` | `pgBoss(boss)` and `work(registry, boss)` |
| `logic-sdk/node` | `startTicking`, crons and sweeps in a long-running process |
| `logic-sdk/fetch` | `toFetchHandler`, a web-standard HTTP handler, and `unauthenticated` |
| `logic-sdk/orpc` | `toORPCRouter`, a typed oRPC v2 router |
| `logic-sdk/ai` | `toAITool` and `toAITools`, AI SDK tools for agents |
| `logic-sdk/testing` | `createTestRegistry` |

## Requirements

- **Node 24 or newer**, Bun, or Cloudflare Workers. The core has no `node:` imports and no `AsyncLocalStorage`.
- **TypeScript:** developed and tested on TypeScript 7. Older versions are untested.
- **A database with interactive transactions** for mutations: Postgres, through Drizzle or [another ORM](/docs/adapters/other-orms). Cloudflare D1 and HTTP-only drivers can't hold a transaction open, so they can't run mutations.
