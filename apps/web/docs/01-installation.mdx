---
title: Installation
description: Add the package, a schema library and a database adapter.
---

```bash
npm i logic-sdk zod
```

Any [Standard Schema](https://standardschema.dev) library works for `input` and `output`. These docs use Zod.

## What's in the package

| Import | What it gives you |
|---|---|
| `logic-sdk` | `init`, the definers, `createRegistry`, errors |
| `logic-sdk/drizzle/pg` | `drizzleAdapter(db)`, and jobs in your Postgres: `databaseQueue`, `outbox`, `failedJobs` |
| `logic-sdk/postgres` | The same three on Postgres with any ORM, and the tables as SQL |
| `logic-sdk/drizzle/sqlite` | `drizzleAdapter(open)` for SQLite on a disk, and the same jobs |
| `logic-sdk/sqlite` | The jobs on SQLite with any ORM |
| `logic-sdk/cloudflare` | `cloudflareQueue`, `handleQueue`, `handleScheduled` |
| `logic-sdk/node` | `work(registry)`: a worker for a long-running process, its jobs and crons |
| `logic-sdk/fetch` | `toResponse`, a domain error as an HTTP response, for your own routes |
| `logic-sdk/orpc` | `toORPCProcedure`, a function as an oRPC v2 procedure for your router |
| `logic-sdk/ai` | `toAITool`, a function as an AI SDK tool for agents |
| `logic-sdk/testing` | `createTestRegistry` |

## Requirements

- **Node 24 or newer**, Bun, or Cloudflare Workers. The core has no `node:` imports and no `AsyncLocalStorage`.
- **TypeScript:** developed and tested on TypeScript 7. Older versions are untested.
- **A database with interactive transactions** for mutations: Postgres, through Drizzle or [another ORM](/docs/adapters/other-orms), or [SQLite on a disk](/docs/adapters/sqlite). Cloudflare D1 and HTTP-only drivers can't hold a transaction open, so they can't run mutations.
