---
title: Meta
description: Your own typed data about each function, read by wrap and adapters.
---

Tags, rate limits, whether an AI agent may call it: anything you want to know about a function from the outside. The shape is declared once, in your config. The values are set per function.

```ts
// logic.ts
type Config = {
  scope: Scope;
  db: Tx;
  meta: { tags?: string[]; agent?: boolean };
};
```

```ts
// a module
export const cancel = mutation({
  description: "Cancel a booking",
  meta: { tags: ["bookings"], agent: false },
  ...
});
```

`wrap` receives it, typed:

```ts
createRegistry({
  modules,
  database,
  wrap: async (call, next) => {
    log(call.id, call.meta?.tags);
    return next();
  },
});
```

Adapters read it from `registry.functions`. A function can't set `meta` unless your config declares its shape. That's the same split as tRPC's `initTRPC.meta<Meta>()` and `.meta({ ... })`.
