# Security

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository ([private vulnerability reporting](https://github.com/fprl/logic-sdk/security/advisories/new)). Please don't open a public issue for it.

Include the version, what an attacker can do, and the smallest code that shows it. You'll get an answer within a week. Fixes land in the latest release; we're on 0.x, so older minors don't get backports.
